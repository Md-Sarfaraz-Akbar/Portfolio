# Md Sarfaraz Akbar — Java Backend Developer Portfolio

A modern, interactive, GitHub-Pages-compatible portfolio focused on Java backend engineering.

## Stack
- HTML5, CSS3, Vanilla JavaScript
- Java 8 / 11 / 17+
- Spring Boot, Spring Framework, REST APIs, JDBC, JSON, Maven
- MySQL, PostgreSQL, SQL
- Git, GitHub, IntelliJ IDEA, Postman
- Azure, Docker, Kubernetes, Terraform, GitHub Actions
- Azure Container Registry, Azure Kubernetes Service, Azure Key Vault
- Prometheus, Grafana

- [Modern DevOps Workflow](https://github.com/AutomationKnights/Software_Deployment_v0)

## Run locally
Open `index.html` in a browser, or serve the repository root with any static web server.

## GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site uses only relative asset paths and requires no backend.
